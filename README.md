# Shivam Singh Chouhan - Personal Portfolio

A personal resume website made with HTML and CSS for the Web Development mid-term assignment.

## Files
- `index.html`: about, education, experience, skills, project, hobbies and contact sections.
- `style.css`: colours, typography, layouts and responsive styling.
- `profile.jpeg`: profile photograph used in the introduction.

## CSS concepts used

Element selectors set general text styles. Class selectors style reusable cards and buttons. ID selectors and anchor links support section navigation. Flexbox arranges the navigation and experience rows; CSS Grid arranges education, skills and hobbies. Media queries adapt the layout for smaller screens. Hover and keyboard focus styles make links easier to use.

The colour palette uses a cream background, dark text and coral accents.
